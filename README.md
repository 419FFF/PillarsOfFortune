Entirely vibecoded Pillars of Fortune plugin for Spigot 1.8.8.

Used Grok Build 4.7 (fast), along with some prompt assistance from Grok 4.6 (Fast).

Commands:

/pof join - Joins a game
/pof leave - leaves a queue
/pof stats - displays your stats or the stats of another player
/pof top - displays a leaderboard of wins

Admin Commands:
/pof start - forces a queue to start
/pof stop - ends all arenas
/pof regen - regenerates all arenas
/pof arenas - lists arenas and their status
/pof debug - shows reasons for eliminations and the arena they died in inside the the console
/pof reload - reloads the config
